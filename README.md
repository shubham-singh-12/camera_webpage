# CodingLab - Hero Landing Page

A clean, minimalist hero landing page built using pure **HTML5** and **CSS3**. It features a modern dark navbar, responsive hero overlay text with interactive call-to-action buttons, and fluid typography.

---

## ✨ Key Features

- **100% Pure HTML & CSS:** Zero JavaScript dependencies for maximum loading performance.
- **Fluid Responsive Typography:** Uses CSS `clamp()` functions for seamless text and UI component scaling across mobile, tablet, and desktop screens.
- **Absolute Centered Hero Overlay:** Background image layout with centered typography and call-to-action buttons.
- **Interactive UI Controls:** Smooth hover and transform animations for navigation links and action buttons.
- **Responsive Layout:** Dedicated media query breakpoints for smaller device viewports.

## 🚀 Getting Started

1. **Clone the repository:**

    ```bash

    ```

2. **Navigate to the project folder:**

    ```bash
    cd camera_webpage
    ```

3. **Run the project:**
